# Calanthor — Master 1‑Page GM Reference (v1.0)

## Core Loop
- **D&D baseline:** d20 checks, AC/HP, initiative, actions.
- **Calanthor spice:** **Procedure Checks** (fail-forward) + **Domain Overlays** (Track 2/4/6) + **Counterplay-first monsters**.

## DCs & Checks
- DC **10** Easy | **13** Standard | **16** Hard | **19** Extreme  
- Roll **d20 + ability mod + proficiency** (if proficient).
- **One-Modifier Rule:** only one source of advantage/+PB applies to the same roll.

## Procedure Checks (Fail‑Forward)
On a failure: you still progress, but pay **one cost**:
- **Time** (extra turn/watch) • **Supply** (-1 SU / kit use) • **Minor Strain** (+1)  
- **Condition** (Chilled/Weighed/Blighted/Haunted/Silenced) • **Tag** (Owed/Suspected) • **Overlay tick** (+1)

## Domain Overlays (Track 2/4/6)
- Track starts **0–2** (typical: **1**).  
- Tick when: obstacle fail, reckless choice (Fast pace), unsafe camp, domain tell triggered.
- **Cadence:** usually **0–1 ticks/watch**, max **2** without a major event.
- **At 2 / 4 / 6:** trigger the domain’s listed beats/events.

## Combat Reminders
- Monsters must have **Counterplay**:
  - **Standard:** 2 counters (2 different categories)  
  - **Elite:** 3 counters  
  - **Boss:** 4 counters (include a **Choice/Bargain**)
- If monster applies **Medium control**, ensure **a way to end it early** exists and is telegraphed (“tell”).

## Condition Quick List (Calanthor)
- **Minor Strain:** currency; **3 = Strained**, **6 = Worn**.
- **Strained:** once/scene GM may impose disadv on 1 roll tied to cause.
- **Worn:** speed -10; no Fast travel; disadv CON saves vs environment.
- **Chilled:** speed -10; first STR/DEX check each turn at disadv. *(reapply → Deep Chilled)*
- **Weighed:** speed -10; disadv Athletics/Acrobatics vs terrain. *(reapply → Anchored)*
- **Anchored:** speed 0; no reactions; ends end of next turn (can be ended early).
- **Blighted:** disadv CON vs poison/disease; healing reduced (1/level or 1). reapply → +1 Strain.
- **Haunted:** disadv Insight/Perception vs deception/illusions; first WIS fail/scene → +1 Strain.
- **Silenced:** no verbal casting (usually 1 round).
- **Marked (Light/Dark):** omen; primarily social impact.

## Social (Disposition Track 0–6)
- Set **Objective** → choose **Frame** (Parley/Investigation/Confrontation/Rite/Deception).
- Start track (0–6). Beats at **2/4/6**.
- Use **Leverage** (Proof/Need/Authority/Reputation/Fear/Mercy) to reduce DC or auto +1 track.
- Tags: **Witnessed, Owed, Suspected, Trusted, Bound by Vow**.

## Exploration & Travel
- **Watch:** ~4 hours (overland). **Turn:** ~10 minutes (site).
- Assign roles each watch: **Navigator, Scout, Lookout, Quartermaster, Ritualist/Witness**.
- **Supply Units (SU):** 1 SU per watch (harsh domains may +1).  
  - At **0 SU:** each watch costs +1 Strain; DC 13 CON save or gain a domain condition.

## Fast Monster Builder (60–120 sec)
1) Choose **CR band** + **Role** (Scout/Bruiser/Controller/Skirmisher/Support).  
2) Pick **Domain/Region** + **Primary Element**.  
3) Pull chassis targets (AC/HP/DPR/Atk/DC).  
4) Add **1 Trait + 1 Signature Action + 1 Twist** (grafts).  
5) Add **Threshold package** (if domain-linked).  
6) Add **Counterplay** (2/3/4 as tier).  
7) Name = **Domain word + Creature word** (e.g., “Oathstone Brute”).
