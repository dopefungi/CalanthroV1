# Calanthor Spell & Class Policy (v1.0)
*5e-compatible magic with Calanthor resonance, techniques, and lore-driven access—without breaking balance.*

This policy answers:
- Do we use standard 5e spells or new bending spell lists?
- How do classes interact with Calanthor’s elements, Great Pets, and regions?
- How do we add “bending complexity” while keeping D&D combat dominant?

---

## 0) The guiding rule
**Combat remains 5e-style.** Calanthor adds *tags, procedures, overlays, and techniques*—not a new spell engine.

---

## 1) The three supported models (choose one; v1.0 recommends Model C)
### Model A — Pure 5e + Tags (simplest)
- Use standard 5e spells unchanged.
- Add Calanthor tags (FIRE/AIR/WATER/ICE/EARTH/VERDANT + domain/motif tags).
- Region Resonance provides small, once-per-scene boosts.

**Pros:** fastest, compatible, easy to run.  
**Cons:** less “bending distinctiveness” for non-casters.

### Model B — Curated/Restricted Spell Lists (more control)
- Use 5e spells, but curate by region/element.
- Some spells become rare or require rites/components.
- Add a small list of Calanthor spells later.

**Pros:** strong setting identity, less kitchen-sink magic.  
**Cons:** high bookkeeping; risks punishing certain classes.

### Model C — 5e Spells + Calanthor Techniques (recommended default)
- Use 5e spells unchanged.
- Add **Techniques** (non-spell abilities) that create “bending-style” play for *casters and martials*.
- Techniques scale by PB and level, not spell slots.
- Region Resonance + Overlays interact with tags for lore congruence.

**Pros:** feels like bending without rewriting spell lists; gives martials element identity.  
**Cons:** requires a small Technique library (but it’s manageable and generator-friendly).

**v1.0 Recommendation:** **Model C**.

---

## 2) Official stance for v1.0 (Model C)
### 2.1 Spells
- Use standard 5e spells and class spellcasting rules.
- Add Calanthor tags per the Tagging Spec.
- Reflavor freely to match Great Pets and regions.

### 2.2 Techniques (new, non-spell abilities)
A **Technique** is a defined action/bonus action/reaction that uses:
- a check, save DC, or attack roll (D&D-native)
- a limited frequency: **PB/Long Rest**, **1/Short Rest**, or **1/Scene**

Techniques are where “bending complexity” lives:
- positioning
- terrain control (small, not encounter-ending)
- protection, mobility, counterplay
- rite-flavored utility

Techniques never replace full spellcasting; they supplement it.

---

## 3) Elemental Disciplines (how characters get techniques)
A character may gain an **Elemental Discipline** in one of three ways (table chooses):

### Option 1 — Background-linked Discipline (setting-first)
Certain culture backgrounds grant a discipline “seed” technique (Tier 0).
This gives low-level characters flavor without flight-level bypass.

### Option 2 — Feat: Elemental Discipline Initiate (recommended for players)
A feat grants a discipline and technique access.

### Option 3 — Subclass modules (campaign-specific)
Create subclasses (e.g., “Ashwalker Oath,” “Sky Sentinel Ranger,” etc.) that grant discipline techniques.

**v1.0 Default:** **Option 2 + light background seeds.**

---

## 4) Region Resonance (official rule; modest by design)
When you cast a spell or use a technique that matches the **local region’s primary element tag**, once per **scene** you may choose one:
- advantage on the spell attack roll, OR
- +1 to spell save DC, OR
- ignore one minor environmental penalty for that effect

**No stacking:** you cannot use this in the same moment as another “once-per-scene” cultural gift unless GM allows.

---

## 5) Great Pet Overlays and magic (how pressure changes casting)
Overlays are usually OFF. When an overlay is Active:

### 5.1 Matching the domain
If your effect matches the overlay’s domain tag (e.g., KALDRAUN_STASIS in a veilstorm scene):
- success-by-5 on a relevant procedure can reduce track by 1 (if fictionally appropriate)
- your magic looks/feels “native” and draws fewer narrative complications

### 5.2 Opposing the domain
If you push hard against the domain (e.g., heavy FIRE in Kaldraun Stasis at track 4+):
- the GM may call for a **CON save** or **Ritecraft check** (DC 15–20) to avoid a complication:
  - minor backlash (Minor Strain)
  - attention (encounter bias)
  - time cost or component cost

**Rule:** this should never become “your class doesn’t work.” It’s about texture and choices.

---

## 6) Ritual policy (Ritecraft integration)
### 6.1 Ritecraft as a tool proficiency (official)
- Ritecraft enables **setting rituals** without creating a new “ritual caster class.”
- Any character proficient in Ritecraft can attempt rites via Procedure Checks.

### 6.2 “Ritualize a spell” (optional)
If a character knows a spell, they may attempt to cast it as a Rite:
- takes 10 minutes (or longer)
- requires a Procedure Check (usually WIS/CHA with Ritecraft)
- success: spell works with added flavor or reduced risk
- failure: complication, not “nothing happens”

Use this to make sacred sites feel alive.

---

## 7) Class-by-class guidance (v1.0)
This is not a rewrite—just “how Calanthor expresses them.”

### Martials (Fighter, Barbarian, Rogue, Monk)
- Gain element identity through **Techniques**, not spell lists.
- Encourage disciplines as feats or background seeds.
- Rogue/Monk shine in procedures and counterplay.

### Half-casters (Ranger, Paladin, Artificer)
- Use standard lists.
- Their discipline techniques should emphasize:
  - Ranger: navigation, terrain reads, restraint/tracking
  - Paladin: vows, ward-circles, restitution rites
  - Artificer: focus items, cairn tech, purification devices

### Full casters (Wizard, Cleric, Druid, Sorcerer, Bard, Warlock)
- Use standard lists.
- Calanthor adds:
  - tags + resonance
  - overlay texture (complications and bargains)
  - techniques as minor “signature moves” (especially for Bards/Warlocks)

### Cleric/Druid note (Gaianok vs “Nature”)
- Gaianok resonance is **VERDANT**: mutualism, growth, stewardship, restitution.
- Not all “nature spells” are Verdant; use tagging spec to decide.

---

## 8) What we are NOT doing in v1.0
- No global restriction of PHB spells.
- No brand-new spell schools.
- No mandatory bending class replacements.
- No “anti-magic region” that shuts down casters.

If you later want tighter identity, we can evolve to Model B (curated lists) in v2+.

---

## 9) Next deliverable (to make this fully playable)
To complete Model C, we’ll write a **Technique Library v1**:
- 6 disciplines (Fire/Air/Water/Ice/Earth/Verdant)
- each with 6–10 techniques in tiers (novice/adept/master)
- balanced usage (PB/long rest, 1/short rest, reactions)
- built-in tags so monsters and regions can respond
