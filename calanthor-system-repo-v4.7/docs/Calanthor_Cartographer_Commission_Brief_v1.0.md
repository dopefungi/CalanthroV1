# Calanthor Cartographer Commission Brief (v1.0)
Prepared for a professional fantasy cartographer to produce a publish‑quality map of **Calanthor**.

This brief is written to be **tool‑agnostic** (Photoshop/Procreate/Illustrator/Inkarnate/CC3+ etc.), and includes:
- required geographic content (what must be on the map)
- stylistic direction (how it should feel)
- deliverables + file specs (so the map is useful for print/VTT)
- Calanthor‑specific “lore layers” (Great Pets, dominion pressure, rite sites)

---

## 1) Project overview
**Setting:** Calanthor — a realm shaped by **Great Pets** (semi‑mythic primal entities) whose “dominions” influence terrain, ecology, culture, and danger.  
**Game use:** tabletop play (D&D‑dominant rules + Calanthor overlays), exploration travel, political/social scenes, and GM secrets.

**Primary map goals**
1) A **world/continent map** that clearly shows the 6 major inhabited regions + 2 lethal ecoregions.
2) A **travel‑usable map** (roads, passes, sea lanes, hazards, border gates).
3) A **GM version** with secrets, overlays, and “pressure fronts.”
4) A **player version** with fewer secrets but strong vibe and readability.

---

## 2) Deliverables (what you will deliver)
### 2.1 Required map outputs
1) **World Map — Player** (labeled, clean, no secrets)  
2) **World Map — GM** (adds dominion pressure, hidden sites, ruin markers, monster ecoregions)  
3) **Regional Insets (2)** (recommended):
   - **Kaldraun–Khalsarra border** (because the starter adventure begins here)
   - **Varook–Charnelix border** (because it’s a major threat edge)
4) **Blank/Unlabeled base** (for VTT fog-of-war / custom naming later)

### 2.2 File formats
- **Layered source:** PSD/PSB or layered TIFF (preferred), or layered PDF/AI if vector.
- **Exports:** PNG (transparent and non‑transparent), JPG (print), and PDF (print).
- **VTT pack:** 70–100 px per grid unit versions (if gridded), plus “no grid” versions.

### 2.3 Resolution & size targets
- World map print: **16×24 in** at **300 DPI** minimum (or equivalent).
- VTT world map: **6000–10000 px** on the long edge.
- Regional insets: **4000–6000 px** long edge.

### 2.4 Typography
- Legible at print size.
- Two type styles (suggested):
  - **Region names:** engraved caps / display serif
  - **Settlement names:** readable serif/sans
- Deliver the font names used (or outline/convert if licensing demands).

---

## 3) Style direction (how Calanthor should feel)
**Vibe keywords:** mythic, harsh, alive, ritualized, weather‑front danger, “nature as law.”  
**Aesthetic:** classic fantasy atlas, but with **dominions as pressure systems** (like storm fronts / currents / fault lines).

### 3.1 Two “looks” (choose one or blend)
**Option A — Atlas parchment**
- ink linework, stippling, subtle watercolor fills
- readable icons (ruins, citadels, gates, shrines)
- dominion overlays shown as faint textures/patterns

**Option B — Painterly realism**
- more environmental painting, atmospheric depth
- overlays shown via color grading and fog/ash/rot texture bands
- icons kept minimal to preserve mood

### 3.2 Iconography (Calanthor‑specific)
Each dominion should have a consistent **symbol set** used in legend and in small map markers:

- **Kaldraun (Frozen Tundra / Stasis):** snowflake / rime spiral / ice shard
- **Khalsarra (Cracked Earth / Burden & Vows):** broken ring / cairn stone / fault glyph
- **Nyvakira (Emberwood / Flame & Renewal):** ember coil / fire-serpent / cinder crown
- **Keairvari (Skyward Peaks / Wind & Height):** wing / wind-knot / storm rune
- **Shakora (Waters / Cycle & Cleansing):** wave / tide knot / river seal
- **Gaianok (Verdant Valley / Growth & Stewardship):** antler‑leaf / root spiral / seed sigil
- **Varook (Gloomwood / Shadow & Memory):** wolf silhouette / eclipse claw / hush mark
- **Charnelix (Sable Mire / Rot & Disease):** web / spore bloom / bone‑reed

## 4) Canon geographic structure (macro layout)
Use this as the **default continent layout** unless you already have a committed shape.

### 4.1 Overall arrangement (recommended)
- **Central-East:** **Gloomwood (Varook)** — massive, dark forest interior
- **East coastline:** **Shakora’s Waters** — cliffs, rocky shores, ports, river deltas
- **North:** **Frozen Tundra (Kaldraun)** — ice fields and highlands bleeding southward
- **West / Northwest:** **Cracked Earth (Khalsarra)** — basalt ridges, ravines, ash roads
- **South / Southeast lowlands:** **Verdant Valley (Gaianok)** — fertile basin, river-lume farms, steward halls
- **Southwest:** **Emberwood (Nyvakira)** — volcanic jungle, cinder glades, obsidian growth
- **Northeast / spine range:** **Skyward Peaks (Keairvari)** — high mountains, cliff cities, wind passes
- **South of Gloomwood / border wetland:** **Sable Mire (Charnelix)** — black wetlands, sinkholes, fungal monoliths

### 4.2 Border logic (important for credibility)
From established lore, Gloomwood borders:
- **East:** coastal cliffs and rocky shores (Shakora influence)
- **North:** snow-covered highlands & icy peaks (Kaldraun proximity)
- **West:** volcanic fields / cracked earth (Nyvakira + Khalsarra adjacency)
- **South:** marshlands and decaying wetlands (Charnelix adjacency)

This is a strong “cardinal” structure — keep it visually obvious.

## 5) Region notes for cartography
These notes tell you what each region should **look like on a map** and what must be labeled.

### 5.1 Kaldraun — Frozen Tundra (Great Pet: Kaldraun)
**Terrain:** polar tundra, glaciers, ice canyons, drift mazes, snow highlands.  
**Map textures:** wind‑carved snow, blue-white crevasse lines, drifting fog bands.  
**Key landmarks (label):**
- **Veilspire Citadel** (glacier‑carved fortress)
- **The Glacial Maw** (vast rift/canyon)
- **The Shardspire** (crystalline mountain)
**Culture pockets:** **Frostborn** camps and signal cairns (sparse, but real).  
**Travel notes:** routes should look dangerous; show one or two “safe lines” (caravan trails).

### 5.2 Khalsarra — Cracked Earth (Great Pet: Khalsarra)
**Terrain:** cracked basalt plateaus, ravines, sink fissures, ash plains, fault ridges.  
**Map textures:** fracture webbing, broken riverbeds, cairn fields.  
**Culture:** **Ashwalkers** travel routes; no permanent cities, but **waystones** and **dirge sites**.  
**Flora/fauna cues:** witherbloom cacti pockets; “wyrm tracks” beneath the earth (optional).

### 5.3 Nyvakira — Emberwood (Great Pet: Nyvakira)
**Terrain:** volcanic jungle, cinder clearings, lava-fed rivers, obsidian groves.  
**Map textures:** dark green canopy with ember veins; smoke plumes; lava deltas.  
**Must include (label or icon):**
- **Obsidian Pines groves**
- **Cinder glades / ember vents** (1–3 major)
**Culture:** **Emberkin** settlements at “safe heat bands,” typically near water and fertile ash soils.

### 5.4 Keairvari — Skyward Peaks (Great Pet: Keairvari)
**Terrain:** dramatic mountain spine, cliffs, narrow passes, wind‑shear ridges.  
**Map textures:** high relief, wind arrows, storm bands at high elevations.  
**Key landmarks (label):**
- **Temple of Winds** (high sanctuary)
- **Cloudspire Cities** (cliffside settlements; 1–3)
**Hazards:** avalanche lines, storm corridors, raptor aerie icons (optional).

### 5.5 Shakora — Waters (Great Pet: Shakora)
**Terrain:** east coast, river deltas, estuaries, tidal flats, coastal cliffs.  
**Map textures:** current lines, tide knots, river networks that feel “alive.”  
**Must include:**
- At least **two major ports** (one treaty‑heavy, one frontier)
- A **river-lume** network feeding Verdant Valley
**Culture:** river-law, diplomats, healers; major roads follow rivers.

### 5.6 Verdant Valley — Gaianok (Great Pet: Gaianok)
**Terrain:** fertile basin, river plains, orchard hills, root bridges, sacred groves.  
**Map textures:** lush green gradients, braided rivers, cultivated marks.  
**Must include:**
- **Steward halls** (2–4 icons)
- **Gaianok’s sacred site** (one major symbol; can be unnamed on player map)
**Note:** Verdant Valley should visually read as the realm’s “breathing food heart.”

### 5.7 Varook — Gloomwood (Ecoregion: dangerous interior; Great Pet: Varook)
**Terrain:** dense old forest, shadowed canopy, shifting paths, silent hollows.  
**Map textures:** dark canopy, mist pools, “path distortion” motifs (subtle spirals).  
**Key cues:**
- No major permanent cities inside; settlements cluster **outside** the boundary.
- Mark **Outskirts lines** clearly; the border feels like a “threshold.”  
**GM-only sites (icons):**
- **Oldest wound** (Varook’s guarded locus)
- **Shadewalker enclaves** (few; optional)

### 5.8 Charnelix — Sable Mire (Ecoregion: unlivable core; Great Pet: Charnelix)
**Terrain:** black wetlands, sinkholes, fungal bogs, spore flats.  
**Map textures:** dark water, rot gradients, web-like channels, spore haze.  
**Key landmarks (label):**
- **Blightwells** (pools of toxic spores)
- **Fungal Monoliths** (bioluminescent towers)
- **Stillbone Trees** (skeletal stands)
- **Cradle of Mold** (GM-only mythic site if desired)
**Settlement logic:** no long-term towns in the deep mire; only border camps/raids.

## 6) Roads, passes, and “gates” (travel usability)
Calanthor wants **travel clarity**. Please include:
- **Primary caravan roads** connecting stable regions (Verdant ↔ Shakora ↔ Khalsarra).
- **Mountain passes** through Skyward Peaks (2–3 named passes).
- **Border forts / gate checkpoints** (icons) at domain boundaries.

**Required named route for the starter adventure**
- **Stone‑and‑Snow Gate** (border checkpoint)
- **Frostcrack Causeway** (narrow basalt bridge)
These should lie on the **Kaldraun–Khalsarra border**.

Optional: add 4–6 additional named crossings (bridges, ferry points, passes).

## 7) Political/territorial layer (recommended)
Even if dominions define the “natural law,” people still claim territory.
On GM map:
- show **influence bands** (soft borders) for cultures/factions
- mark **treaty zones** (where law and witness rites are strongest)
On player map:
- keep borders softer and more mythic

## 8) Dominion pressure overlay layer (GM map only)
This is the “Calanthor special.” Treat dominions like meteorological systems.

### 8.1 How to draw it
- faint patterns or semi-transparent textures that fade at edges
- pressure fronts along borders (like weather maps)
- glyphs at Track 2/4/6 “hotspots” (optional)

### 8.2 Suggested overlay motifs
- **Stasis (Kaldraun):** drifting bands, crystalline fractals
- **Weight/Vows (Khalsarra):** ringed fissures, cairn field stippling
- **Rot/Disease (Charnelix):** webbed channels, spore bloom dots
- **Shadow/Memory (Varook):** veil gradients, eclipse arcs
- **Cleansing/Cycle (Shakora):** current lines, tide knots
- **Growth/Stewardship (Gaianok):** root veins, leaf lattices
- **Wind/Height (Keairvari):** wind arrows, storm halos
- **Ember/Renewal (Nyvakira):** cinder drift, ember vein glow

### 9.1 Naming “feel”
- **Kaldraun:** cold, sharp, breath, drift, shard, veil, rime
- **Khalsarra:** oath, cairn, fault, dirge, ash, weight, hollow
- **Nyvakira:** ember, cinder, obsidian, coil, forge, bloom
- **Keairvari:** wind, spire, cloud, pass, storm, aerie
- **Shakora:** tide, river, lumen, estuary, seal, harbor
- **Gaianok:** grove, root, warden, steward, spring, meadow
- **Varook:** hush, shade, wraith, memory, veil, hollow
- **Charnelix:** mire, spore, stillbone, blight, web, mold

### 9.2 Label density (readability)
- World map: 30–60 labels max (plus legend)
- Insets: 40–80 labels max depending on size
- Use icon-only markers for some GM secrets.

## 11) Questions the cartographer should ask you (answer before final pass)
To avoid revisions, decide these early:
1) Do you want Calanthor as **one continent** or an **archipelago**?
2) Do you want a **grid/hex** on the VTT versions? If yes, what scale?
3) Which 10–20 settlements are “canon names” vs placeholders?
4) How “literal” are Great Pet borders (hard line) vs (soft gradient)?
5) Do you want rivers to be **highly detailed** (hydrologically plausible) or stylized?
6) Any real-world map references you like (Tolkien, Witcher, Skyrim, etc.)?

---

## 12) Suggested production workflow (professional)
1) **Thumbnail layouts** (3 options) — continent shapes + region placement
2) **Approved line draft** — coastlines, rivers, relief, borders
3) **Label pass v1** — major labels + icon placements
4) **Color/texture pass** — region identity locks in
5) **GM overlay layer** — dominion pressure + secrets
6) **Final typography polish** — readability checks
7) **Exports** — print, VTT, unlabeled, GM
