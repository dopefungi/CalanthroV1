# Calanthor Class Edge Catalog (v1.0)
*Class-unique skill modifiers that add Calanthor flavor without breaking D&D balance.*

## What a Class Edge is
A **Class Edge** is a small, reliable, **non-combat** advantage that makes your class feel distinct during:
- Procedure Checks (travel, hazards, rites, negotiations)
- high-stakes skill checks (investigation, infiltration, endurance)

Class Edges do **not** add damage, do not change AC/HP, and do not rewrite spellcasting.
They exist to:
- reduce “bad luck spirals”
- reward identity-driven play
- make Calanthor procedures feel heroic and specific

---

## 1) Core rules (official)
### 1.1 Gain
You gain **one Class Edge** at **level 1** (choose from your class list).

### 1.2 Frequency
- **1/scene** you may use your Class Edge.
- A “scene” is a meaningful obstacle, encounter, negotiation, or travel beat.

### 1.3 What it does (choose one when you use it)
When a Class Edge applies, choose **one** effect:
- **Boost:** add **+PB** to the roll, OR
- **Stabilize:** convert a failure into **success with a cost** (use the Procedure Failure Menu; GM chooses/negotiates cost)

**Restriction:** A Class Edge cannot be used on attack rolls or damage rolls.

### 1.4 The One-Modifier Rule (anti-power-creep)
On any single roll, you may apply **only one** of:
- Culture Gift (background)
- Class Edge
- Region Resonance / Region Attunement passive

(No stacking unless GM explicitly allows for climactic moments.)

### 1.5 Upgrades (optional but recommended)
- **Level 5+:** you can use your Class Edge **twice per scene**, OR once per scene you may apply it to an ally you can meaningfully assist.
- **Level 11+:** once per long rest, during a Procedure Check with no immediate lethal stakes, you may treat the d20 as a **10** before modifiers (a “steady hand” moment).

## 2) Class Edge options by class
Each class gets 2–3 choices. Choose the one that best matches your character concept.

### Barbarian
**A) Storm-Heart Endurance**  
Applies to: CON saves, Athletics, Survival, forced march, exposure, carrying, breaking through.  
Flavor: you endure what should break you.

**B) Intimidating Presence (Primal)**  
Applies to: Intimidation, contested will, stare-downs, forcing passage, “don’t test us.”

### Bard
**A) Silver Tongue Protocol**  
Applies to: Persuasion, Deception, Performance, treaty scenes, mediation, “buy time.”

**B) Lore-Thread Recall**  
Applies to: History, Arcana, Insight, reading a room, uncovering what matters.

### Cleric
**A) Rite-Surety**  
Applies to: Religion, Ritecraft checks, purification, blessings, warding circles.

**B) Mercy’s Authority**  
Applies to: Persuasion/Insight when preventing violence, offering restitution, or calling for truce.

### Druid
**A) Mutualist Hand**  
Applies to: Nature, Medicine, Animal Handling, Verdant hazards, calming ecosystems.

**B) Weather-Read**  
Applies to: Survival, Nature, Perception when predicting storms, timing crossings, reading wind/water.

### Fighter
**A) Vanguard Bearing**  
Applies to: Athletics, Intimidation, commanding a breach, holding formation, protecting civilians.

**B) Tactical Appraisal**  
Applies to: Investigation, Insight, Perception to read battlefield terrain, ambush lines, enemy intent.

### Monk
**A) Centered Breath**  
Applies to: Acrobatics, Athletics, CON saves vs exposure, balancing, “move through harm.”

**B) Still Mind Discipline**  
Applies to: WIS saves, Insight, resisting fear/memory pressure (Varook motifs), keeping focus.

### Paladin
**A) Vow & Witness**  
Applies to: Religion, Persuasion, Insight, Ritecraft when vows, oaths, and restitution are involved.

**B) Beacon of Resolve**  
Applies to: Persuasion/Intimidation to rally allies, stand ground, refuse despair (Khalsarra motifs).

### Ranger
**A) Trail Sovereignty**  
Applies to: Survival, Perception, Nature, travel Procedure Checks, tracking, route choice.

**B) Quiet Approach**  
Applies to: Stealth, Survival, Animal Handling to move unseen, bypass threats, avoid attention.

### Rogue
**A) Shadow’s Angle**  
Applies to: Stealth, Sleight of Hand, Deception, infiltration, bypass, escape.

**B) Pattern Exploit**  
Applies to: Investigation, Perception, Insight to spot weaknesses, loops, tells, hidden mechanisms.

### Sorcerer
**A) Resonant Instinct**  
Applies to: Arcana, CHA checks to shape raw magic, resist backlash, or stabilize wild effects.

**B) Elemental Lean**  
Applies to: Procedure Checks or Arcana tied to your primary element tag (FIRE/AIR/WATER/ICE/EARTH/VERDANT).

### Warlock
**A) Pact Leverage**  
Applies to: Deception, Intimidation, Persuasion in bargains, leverage, true-name tension, intrusion logic.

**B) Invocation Thread**  
Applies to: Arcana, Insight, or Procedure Checks to “route” power through a focus, token, or vow.

### Wizard
**A) School Savant**  
Choose a school (e.g., Necromancy, Illusion). Applies to: Arcana and Procedure Checks involving that school’s logic (wards, death-marks, illusion-threads).

**B) Methodical Proof**  
Applies to: Investigation, Arcana, History when building a case, decoding, mapping a hazard, predicting outcomes.

## 3) GM guidance (how to keep it fair)
- Encourage players to justify how the Edge applies; if it fits, it works.
- Use Edges as “hero points” for procedures—not combat math.
- When in doubt, allow **Boost (+PB)**. Reserve **Stabilize (success-with-cost)** for when the roll would stall the session.

## 4) Generator notes (minimum data)
Each character should store:
- chosen class edge id
- uses per scene (1; upgrades at level 5)
- eligibility tags (skills, motifs, domains)
