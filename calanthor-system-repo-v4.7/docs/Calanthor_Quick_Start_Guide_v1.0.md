# Calanthor Quick Start Guide (v1.0)
*A table-ready “start playing tonight” guide for the Calanthor hybrid (D&D-dominant) system.*

This Quick Start assumes you have the Calanthor repo and are using:
- D&D-style d20 checks, initiative, actions, AC/HP
- Calanthor modules: Procedure Checks, Domain Overlays, Techniques, and Role-First Monsters

---

## 1) What you need to play
- 3–6 players + 1 GM
- d20s + damage dice
- Character sheets (or D&D-like sheets)
- The **Core** Calanthor rules set (listed below)
- The **First Adventure** (included separately)

---

## 2) The “Core Set” you actually need at the table
Use these docs as your *minimum* rules stack:
1. **Procedure Check Usage Rules** (fail-forward, luck smoothing)
2. **Domain Overlay Operating Rules** (track 2/4/6 pressure)
3. **Technique Library** (class technique picks)
4. **Monster Role Chassis Tables** + **Graft Libraries** + **Counterplay Templates**
5. **Core 20 Arms List** + **Starting Gear Matrix**
6. **Social Interaction Framework** + **Exploration/Travel Procedure**

Everything else is optional for session 1.

---

## 3) The Calanthor “loop” in one paragraph
Players take actions like in D&D, but the world pushes back via **Domain Overlays** (a track with beats at **2/4/6**).
When you fail checks, you still make progress (Procedure rules), but you pay costs like time, supplies, Minor Strain, tags, or overlay ticks.
Monsters are designed with **counterplay**, so pressure is scary but fair.

---

## 4) Character creation (10 minutes per player)
### Step 1 — Choose lineage + background
- Use **Official Lineages/Backgrounds** OR use a D&D lineage reskin from the **Species Reskin List**.
- Pick a **Background** from the **Starting Gear Matrix** (recommended for Quick Start).

### Step 2 — Choose class
Use your Calanthor class policy + techniques. For quick start:
- **Fighter / Barbarian / Ranger / Rogue / Cleric / Druid / Wizard / Sorcerer / Bard / Paladin** work cleanly.
- If you’re not ready for full class conversion, run straight 5e classes and add:
  - Calanthor **Technique picks** (1–2)
  - Calanthor **Procedure + Overlays**

### Step 3 — Ability scores and basics
- Use standard D&D method (array/point buy/rolls).
- Proficiency bonus and leveling: standard D&D cadence.

### Step 4 — Starting gear (fast)
- Choose 1 weapon from the **Core 20** (or from your background list).
- Choose 1 implement (if relevant).
- Take your background kit.
- If the GM allows: one PC may start with **Tier 2 Ritebound** gear + a **Debt**.

---

## 5) How checks work (quick)
- Roll **d20 + modifier + proficiency** (if proficient).
- DCs: 10 easy / 13 standard / 16 hard / 19 extreme.
- **Procedure rule:** low rolls still move forward with a cost. You don’t “waste” scenes.

Common check lanes:
- **Survival** (navigation, weather)
- **Ritecraft** (witness lines, vows, wards)
- **Medicine/Nature** (contamination, antidotes)
- **Insight/History** (social leverage, treaty precedent)
- **Athletics/Acrobatics** (terrain, bracing, escapes)

---

## 6) Combat in Calanthor (still D&D)
Same as D&D with these Calanthor defaults:
- Monsters include **counterplay** (resource + skill + choice).
- If a monster applies **Medium control**, the GM must present a way to end it early.
- Domain overlays can add pressure beats (2/4/6), but never remove player agency.

**Use the Monster On‑the‑Spot Builder** when you need enemies quickly.

---

## 7) Social play (fast)
Use the Social Framework:
- Pick objective
- Set Disposition track start (0–6)
- Track beats at 2/4/6
- Use **Leverage** and **Tags** (Witnessed, Owed, Suspected, Trusted)

Most social scenes resolve in 3–6 meaningful rolls, not 30 minutes of dice.

---

## 8) Exploration play (fast)
Use the Exploration/Travel procedure:
- Travel in **Watches** (~4 hours)
- Assign party roles
- Spend **Supply Units (SU)**
- Run 1 obstacle per watch
- Overlay ticks happen on fails, reckless choices, and unsafe camps

---

## 9) Conditions (provisional list for Quick Start)
Until your full Condition Appendix is finalized, use these “table shorthand” conditions:
- **Minor Strain:** fatigue/stress. Track it narratively; 3+ strains should matter.
- **Chilled:** -10 speed; disadvantage on one check/attack if extreme cold is the cause (GM).
- **Weighed:** speed -10; disadvantage on Athletics/Acrobatics vs terrain (GM).
- **Blighted:** disadvantage on CON saves vs contamination; healing reduced by 1/round (GM light touch).
- **Haunted:** disadvantage on Insight/Perception vs deception/illusions (GM light touch).
- **Silenced:** cannot use verbal casting until end of next turn (as written).

Keep these light—don’t overstack penalties.

---

## 10) GM setup for session 1
- Choose a domain focus (recommended: **Kaldraun + Khalsarra border**).
- Start overlay track at **1** (ominous but not punishing).
- Plan 3 pillars:
  1) a **parley** at a gate or caravan
  2) an **exploration** obstacle (weather/terrain)
  3) a **fight** with counterplay-forward monsters

Use the included first adventure to do exactly that.
