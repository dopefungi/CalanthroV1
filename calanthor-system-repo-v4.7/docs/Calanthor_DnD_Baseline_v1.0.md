# Calanthor D&D Baseline (v1.0)
*A 5e-compatible baseline tuned for Calanthor’s Great Pets, regions, and domain pressures.*

This baseline keeps **D&D-style combat** intact while aligning exploration, culture, and magic with Calanthor lore.

---

## 1) System compatibility
- **Core math:** use 5e-style ability mods, proficiency bonus (PB), AC/HP, actions, spells, saves.
- **Combat rules:** use your preferred 5e core (PHB/DMG/MM style). Calanthor adds *regional procedures, domain pressures, and cultural options*—not a new combat engine.

> If you are using a specific 5e variant (2014 vs 2024), treat this baseline as a setting overlay. When in doubt, keep the edition’s default for combat timing and spell rules.

---

## 2) Core resolution (Calanthor procedures)
### Basic roll
**d20 + ability mod + PB (if proficient)** vs a DC.

### DC guidance
- **DC 10** Easy (good conditions, ample time)
- **DC 15** Standard (typical danger/pressure)
- **DC 20** Hard (hostile region, time pressure, active hazard)
- **DC 25** Extreme (mythic pressure, catastrophic weather, Great Pet attention)

### Optional margin rule (recommended)
- **Success by 5+**: add an extra benefit (shortcut, advantage next related roll, recover 1 supply, reduce an active domain track by 1, etc.).
- **Fail by 5+**: harsher consequence (lose supplies, separation, attract a threat, increase an active domain track by 1, etc.).

### Procedure Checks (the replacement for “Moves”)
A **Procedure Check** is simply a named, repeatable D&D check for:
- travel and navigation
- rites and bargains
- hazard crossing
- mediation and faction pressure

Each Procedure Check defines:
- **Trigger**
- **Check** (ability + skill/tool)
- **DC guidance**
- **Success / Failure outcomes** (and optional margin outcomes)

---

## 3) Skills and proficiencies
### Skill list
Use the **standard 5e skill list** (no new skills required).

### Calanthor adds “Ritecraft” as a tool proficiency (not a skill)
- **Ritecraft (Tool Proficiency):** chants, offerings, ward-knots, cairn rites, purification patterns, vow-binding circles.
- A Procedure Check may call for **WIS (Ritecraft)** or **CHA (Ritecraft)**, etc.

Why this choice: it avoids rebalancing class skill access while giving “ritual competence” mechanical teeth.

---

## 4) Rest cadence and safe shelter
Calanthor regions can be brutal; rest rules remain 5e but require **fictional safety**.

### Short Rest
- **1 hour**, as normal.
- In hostile regions (Cracked Earth, Frozen Tundra, deep Gloomwood, Mire), a short rest requires **shelter** (cairn, cave, ward-circle, hidden ledge, stilt camp, etc.).
- If no shelter: you can still rest, but someone must succeed on a **DC 15 Procedure Check** (Survival/Investigation/Ritecraft depending on region) or the party gains **Minor Strain**.

### Long Rest
- **8 hours**, as normal.
- Requires *relative safety*. In regions with an active **Domain Pressure**, the GM may require:
  - a shelter check, **or**
  - a ritual/offer, **or**
  - a cost (supplies, time, vow)

> Goal: the world feels alive, but rests aren’t constantly denied. Use costs and complications more than flat “no.”

---

## 5) Calanthor conditions
### Minor Strain (setting condition)
**Minor Strain** represents exposure, fatigue, numbness, dread, coughing spores, brittle breath, etc.

Default:
- While you have Minor Strain, take **-1** on your next d20 roll that meaningfully relates to the cause.
- Clears on a short rest or earlier if fictionally addressed (warmth, witness, ritual, remedy).

(You can optionally define a “Major Strain” later, but v1.0 does not require it.)

---

## 6) Magic in Calanthor (tags + resonance)
### Spell sources
Use standard 5e spells. Calanthor adds **tags** for generation and regional flavor.

### Element tags
- **Fire, Air, Water, Verdant, Earth, Ice/Winter**

A spell/feature may have 1–2 tags.
- **Explicit tagging** is preferred (most consistent for generators).
- If you must auto-tag: use damage types as a fallback (fire→Fire, cold→Ice/Winter, thunder/lightning→Air/Storm, poison/disease→Blight, psychic/fear/illusion/silence→Silence/Memory).

### Regional resonance (small, non-breaking)
When casting a spell that matches the local region’s element tag (GM discretion):
- once per **scene**, the caster may gain **one**:
  - advantage on the spell attack roll, **or**
  - +1 to the spell save DC, **or**
  - ignore one minor environmental penalty (fog, wind, slick ice) for that spell

This is intentionally modest to avoid power creep.

---

## 7) Great Pets and Domain Pressures (Overlays)
Each region has a **Domain Pressure** overlay (track 0–6).

### Default rule
- Domain Pressures are **OFF** unless the GM turns them on for:
  - mythic moments
  - disasters
  - sacred sites
  - Great Pet attention
  - deep subzones (e.g., Deep Gloom, Deep Mire)

### Track scope
- Default scope is **party-wide** when traveling, or **scene-wide** in a focused setpiece.
- Individuals may carry personal marks as story consequences, but the track remains manageable.

### Track philosophy
- Tracks create **choices** (detours, rituals, vows), not constant attrition.
- Recovery is possible via shelter, rites, restitution, and smart play.

---

## 8) Cultures as Backgrounds (recommended)
Calanthor cultures are best represented as **Backgrounds** (or background-like packages), not species—unless you explicitly want a non-human physiology.

Examples:
- **Frostborn Whisperer** (Frozen Tundra): omen-reading, cairn rites, survival logistics
- **Ashwalker Vow-Bearer** (Cracked Earth): endurance, binding chants, purpose discipline
- **Emberkin Rite-Dancer** (Emberwood): renewal ritecraft, volcanic navigation
- **Aeris Sky-Sentinel** (Skyward Peaks): wind-reading, altitude discipline
- **Shakoran Mediator** (Waters): treaties, purification, river-law
- **Gaianok Steward** (Verdant): mutualism, herbcraft, ecosystem diplomacy

Each background should grant:
- 2 skill proficiencies (5e standard)
- 1 tool proficiency (often **Ritecraft**)
- 1 language
- 1 feature (setting benefit)

---

## 9) Flight in Calanthor (balanced progression)
True flight is balanced with **Aerial Mastery** + **Aerial Strain** (see Rules Kernel v2).

Baseline policy:
- If a species/background grants wings, it grants **Tier 0 (Jump + Glide)** at level 1.
- Higher tiers unlock by level (5/9/13/17+) **or** by taking a feat/class feature (your choice).

This keeps low levels grounded while letting mid/high levels become aerial tacticians.

---

## 10) Character creation (Calanthor steps)
1. Build character using 5e rules (class, abilities, equipment).
2. Choose a **Calanthor Region Attunement** (if appropriate for your campaign):
   - grants a small passive (1/scene) and a surge (1/short rest) *or* background feature equivalents.
3. Choose a **Culture Background** (Frostborn, Ashwalker, etc.).
4. Record relevant tags (element preferences, ritecraft, survival specializations).
5. GM decides which **Domain Pressure** overlays might be active in early arcs.

---

## 11) GM calibration rules (to keep play fun)
- Prefer **costs** and **hard choices** over “you fail and nothing happens.”
- Use Domain Pressure tracks sparingly but meaningfully—turn them on when you want the region to feel mythic.
- Never let tracks create a “no-rest forever” lock; always offer a path (ritual, shelter, bargain, detour).

---

### Appendix: “What this baseline does NOT change”
- Attack rolls, damage, AC, HP, initiative, action economy.
- Spell slot progression and core spell rules (unless you intentionally homebrew them).
- CR math (unless you later choose to rebuild it).
