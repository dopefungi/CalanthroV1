# Calanthor Core 20 Arms List (v1.0)
*A curated, table-friendly weapon list for Calanthor campaigns.*

**Why a Core 20?**  
This list keeps play fast and clean. Everything else becomes:
- **Optional** (available in treaty markets)
- **Region‑locked** (common only in certain dominions)
- **Ritebound/Pet‑Marked** (story items)

**Compatibility:** Damage dice and properties follow standard 5e baselines.

---

## Region‑locked add‑ons (common *only* in these places)
Use these when the party is *there*, or when a PC is from there.
- **Trident** (Shakora / Waters)
- **Net** (Shakora patrols, Charnelix border)
- **Sickle** (Verdant Valley + Charnelix border)
- **Whip** (Emberwood rite‑dancers, Varook border handlers)
- **Halberd** (Keairvari watch lines)
- **Heavy Crossbow** (border forts)

## Calanthor signature variants (upgrade path)
Any Core 20 weapon can gain Calanthor identity by tier:
- **Tier 1 Clanwork:** tags + tiny procedure utility
- **Tier 2 Ritebound:** 1 resonance hook
- **Tier 3 Pet‑Marked:** 2 hooks, story-earned

See: **Calanthor Weapons & Implements** and **Equipment Tiers/Crafting/Loadouts**.
